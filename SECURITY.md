# Security Policy

## Supported versions

Only the latest release of TaskSession CRM receives security fixes. Please keep your installation up to date.

## Reporting a vulnerability

**Please do not open a public GitHub issue for security problems.**

Report vulnerabilities privately using GitHub's **[Report a vulnerability](https://github.com/tasksession/tasksession-crm/security/advisories/new)** form (Security tab → Advisories).

Please include:
- A description of the issue and its impact
- Steps to reproduce (URL, request, payload)
- The TaskSession version you tested

We will confirm receipt, investigate, and release a fix as soon as possible. Thank you for helping keep TaskSession users safe.
